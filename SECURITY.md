# Segurança

LINBLUX Alpha executa experiências e scripts locais. Use conteúdo de origem
confiável e cópias de projetos importantes. Não há promessa de isolamento contra
código hostil nem infraestrutura multiplayer de produção nesta versão.

Para comunicar uma vulnerabilidade, use a opção **Report a vulnerability** na aba
Security do GitHub, quando disponível. Se ela não estiver habilitada, abra uma
issue solicitando um canal privado, sem publicar exploit, credenciais ou arquivos
pessoais. Não há prazo garantido de resposta nesta fase experimental.

Inclua versão/commit, ambiente, impacto e passos mínimos de reprodução. Não
anexe experiências privadas ou segredos em issues públicas.
