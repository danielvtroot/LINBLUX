# LINBLUX Alpha 0.1.0 — rascunho, não publicado

Engine 3D open-source para criação de experiências no Linux.
Studio, Player, mundos locais `.lo`, física Bullet e Lua controlando objetos,
NPCs, áudio, inventário e interfaces. Esta versão inclui a demonstração
programável RifleDemo, HUD circular e menus laterais nas interfaces padrão.

Estado atual: candidato interno. NÃO criar tag/Release enquanto os bloqueios
registrados em ../ALPHA_0_1_0.md não forem resolvidos. O pacote deste ambiente
não é apresentado como compatível com todas as distribuições Linux.

Veja ../CHANGELOG.md e as instruções de instalação. MP4 de fundo omitido por
padrão; sem multiplayer, rigs arbitrários, áudio3D ou inventário de partida
salvo automaticamente. Código e recursos são descritos conforme implementação
real e não como promessa de APIs completas.
